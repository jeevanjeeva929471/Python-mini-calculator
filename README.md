Python Mini Calculator

A simple calculator project built using Python.

Features

- Addition
- Subtraction
- Multiplication
- Division
- User input
- Operation selection using if-elif-else
- Invalid operation handling

## Concepts Used

- Python Functions
- User Input
- Type Casting
- If-elif-else
- Function Calling

## How to Run

1. Run the `mini.py` file.
2. Enter two numbers.
3. Enter an operation: `+`, `-`, `*`, or `/`.
